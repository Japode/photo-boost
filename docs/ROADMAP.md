## Done when — PB12

- **The manifest and model files are published at a stable URL** build-manifest.py ran
  with the real --base-url, every staged file is reachable there, and a download checks
  against the manifest's SHA-256.

## Done when — PB52

- **No user upscale on --provider winml pays the engine build** After the first launch
  the engines are built in the background; a run started once that finished takes under
  DirectML's first-run time on the RTX 4060 desk.
- **Auto runs on TensorRT-RTX where its engine is cached** With an engine cached,
  --provider auto's status bar names TensorRT-RTX on the RTX 4060 desk, and DirectML
  still runs where no engine or provider exists.

## Done when — PB57

- **A Save as case checks the exact file the dialog was told to write** The case reads
  "Saved saved.png" after choose file, and passes on the host and on the VMware guest in
  two runs in a row.

## Non-goals

- **Cloud inference or external APIs** Every model runs locally; the network is used
  only to download model files on first launch.
- **Models committed to the repository** Weights are fetched and generated by scripts
  and stored in userData/models, never in git.
- **Builds for macOS, Linux, web or mobile** PhotoBoost is Windows-only, so it can use
  DirectX, DirectML and the WPF stack shared with the sibling apps.
- **A WinUI 3 user interface** claude-tray, quickshell, pportal and winwright's in-app
  package are all WPF with the Fluent ThemeMode, so WPF reuses their design and tests as
  they are.
